# Parole Trentine

Dizionario digitale della lingua trentina.

## Features
- 🔍 Search with debounce
- 📖 Rich word cards
- 📊 Admin dashboard
- 📤 Excel import
- 🔐 Authentication

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Supabase
- TanStack Query

## Setup
```bash
npm install
npm run dev
```
